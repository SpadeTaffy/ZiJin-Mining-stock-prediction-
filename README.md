# ZiJin-Mining-stock-prediction-  
## 项目动机  
受Kaggle金价预测的想法,反过来利用机器学习预测中国A股市场的紫金矿业股票的学习记录,因为我自己重仓了紫金矿业,结合最近伊朗危机石油价格大幅波动,想要去用数据分析来辅助自己的买卖点,实现价值投资选择股票,技术分析判断情绪与历史数据三重判断.

## 投资的心得  
1. 不同行业都有周期,以现在的眼光看某一个板块热门,但可能在过去十几年间大部分是跑输指数的,但是实际上股票市场的价格回归是突然的而不是缓慢渐进的,比如黄金板块21年前一直跑输指数,21年后却一直高于指数,且近年来股价飞涨.股票的价格,根本决定于供需关系,而这种供需关系,仍然取决于公司商业模式的景气度与公司经营情况的基本面.
2. 不要带着答案找问题,自己提出的猜想应该要能被证伪.金融市场的表现往往呈现周期性,某些牛熊时期的数据叠加外部冲击,反映在股价上,单纯地以统计学来得出经济规律,可能具有误导性.且得到相同的变量之间的相关性,不代表它们互为因果.

## 项目的结论  
1.1.
&emsp;以2026年的视角来看,以扣非净利润为代表的实际营业能力加权得到的指数,涨幅在2012-2026年间一直大于市值加权得到的指数.在市值加权下,龙头占比67%,扣非净利润加权下,龙头占比72%,花更多的钱在龙头上,得到的投资结果略好一些,可能代表龙头的营业能力更强,单位投资获利更高,变相地说明了可能因为ETF板块,让更多的钱流入了小票之中,投资效率相对更低一点.  
1.2.
&emsp;如果对选中的板块拿不定主意,对所有的股票用同等的权重进行投资,那么只会得到一个很平庸的数据,总体来看只有集中投资龙头的1/2左右的收益.  
&emsp;跟据价值投资的原则,适度的分散可以,但是选择一个宽泛概念的过度的分散会导致一个很差的投资回报.集中投资和平均投资主要看行业的景气度,趋势相同,但是随着时间的推移行业内部分化严重.  
1.3. 
&emsp;宽泛的概念如有色金属概念(sh000819)随着时间推移表现很差,整体趋势上受黄金影响,但是幅度较弱,收益是最差的.在有色金属层面,宽泛投资不如定点投资,选择具体的龙头企业而不是宽泛的买ETF,浪费资本,还会被收取管理费.  
1.4.
&emsp;如果投资A500或者沪深300,从12年开始算到2026年7月26日,不算分红的话收益只有104%和74%,年化回报率按照14年来算的话,分别为5.28%和4.03%.长远来看,鉴于A股低分红率的历史,选择股息率5%以上的股票,至少是可以保证获得平均的资本增值回报.  
1.5.
&emsp;在指数编撰上,A500是把不同行业的龙头都纳入进去,而非沪深300单纯的以市值和流动性计算.鉴于目前沪深300有很多科技股票,市值高而非业绩稳定,且金融等央企比重较大,不能反应各个领域最有竞争力的企业实际情况.因此,长期来看A500跑赢沪深300也是正常的.  
   根据结论1,2,3,把钱放在中小票上,他们的资本利用率与投资回报率是不如龙头企业的.且过于宽泛的概念投资,不如押注某一个具体方向的龙头,或者押注完全不同的经济领域而非宽泛概念.  


结论1:&emsp;投资应该选择 **绩优** 的蓝筹股,不要选择过多的未产生稳定业绩的科技股,不要选择任何宽泛的概念,分散投资选择不同经济领域的,尽量集中持有.结合凯利公式和价值投资的思想,我对自己的判断是最大仓位为27%,但是根据次优的50% **凯利公式** ,把大部分仓位限制在15%以内,牺牲一定的利益来换取投资组合的稳定性.也就是说,持仓对我而言保持在8支左右是最好的.如果你比较自信,那么选择优秀的个股是比被动买入指数要好的.

2.1. &emsp;黄金价格与黄金股票呈现正相关性,在极端情况下更明显,但只能说是 **可能性较大** 而非一定,也就是说黄金上涨股票也有可能跌,即使是上涨,同样的黄金价格变动,股票对应的涨跌幅范围更加大.也就是说, **股票价格** 受多种因素影响,比如说资金面,宏观经济,价值回归,情绪消息等多重因素共同影响.大部分时间,金价的波动与股价关系都是杂音,不必去理会.  
2.2. &emsp;黄金和指数在平日里几乎是毫无关系,但是在大涨大跌中有微弱的正相关关系,可能反映的是流动性的充裕,可能代表的是宏观投资环境变化.也有可能是极端行情中,避险情绪和市场风格刚好重合,两者可能受到其他因素影响,统计上呈现正相关性.
2.3. &emsp;用CPI作为通胀的标准时,需要考虑到通胀是外部输入的结构性通胀还是经济过热引起的通胀.有可能你以CPI判断标准,正好踩上了疫情等宏观经济或者周期性牛熊市的时段,因为样本量较小可能会得到一个错误的结论.  
2.4. &emsp;想要证明两者相关,先用卡方独立性零假设设定无关,用拒绝原假设,选择备择假设来证明数据的相关性.  
2.5. &emsp;金融数据的时间也隐含着信息,因为不同时间段的市场环境不同,在进行构思时,应先对今年的宏观经济和市场风格有所了解,根据时段进行分类研究.  
结论2:&emsp;在验证自己的猜想时,应该意识到数据的时间维度的重要性,否则在根据数据进行分析时,金融数据会受外部事件影响,在样本量较小的情况下可能会得出一个非普遍的规律.根据一个假设得到结论时,不应该认为自己发现的随机结果具有普遍规律,需要用统计方法来检验它,并且怀疑是否自己的前提设计的有问题,错误的问题会导致错误的答案.在不断的数据探索中,提出新的问题并验证,这样才能得到一个更加贴近现实的答案.  
  
3.1. &emsp;期货具有大小月,如何处理这个月份是将期货交易量作为因子的首要工作.  
3.2. &emsp;在处理金融数据时,要用一个滑动窗口,是采用平均还是指数加权,窗口大小的选择应该怎么选,应该多加尝试.  
3.3. &emsp;交易量与供需关系理论上应该无关,不影响基本价值,但是可能影响情绪,进而推动价格.  
3.4. &emsp;但是,错误的问题只会得到错误的答案.我不知道真正的关系是什么,以我探究的方法,我得出结论是期货成交量下降没有什么规律,而量价齐升的规律比较微弱.但是如果我一开始提出的问题错了,处理数据的方法不对,那我得出来的结论也是错误的.  
3.5. &emsp;最后根据数据探索,可能孤立来看这些变量没什么联系,但放在模型中作为因子,是否选用这个因子,这个因子应该选择数据探索中的哪一个值,应该以模型实际预测准确度为准,来判断是否使用.  
结论3:&emsp; 对于期货,应该用合理的方法来处理它.不像股票每天都有交易日,主力合约的限制让交易主要集中在某一个月的最后几天.因此要首先正确处理数据,提出正确问题才能得到正确答案.假定我的方法没问题,那么最后在代入模型中以实际情况为准,决定是否使用这个数据,如果没有效果或者下降,则是杂音.

## 反思问题
1. 在获取股价的时候,我默认采用的都是除权模式,而在分红,送股等可能会造成数据的暴跌,我没有考虑过这个问题,之后会单独采用前复权,后复权来验证不同条件下数据是否会对预测产生影响.
2. 在编撰自己的黄金指数时候,不能把不同价位的股票加起来得到一个总和,否则就和道琼斯指数一样,变成价格加权指数,股价高的影响更大.如果采用等权重,必须用每个股票股价变化的百分比来计算.
3. 在整合不同数据集的时候,一般需要将时间转成Datetime格式来作为索引,将不同的数据通过相同的时间来合并成一个新的表,避免错误的索引拼接导致Nan的出现.
4. 在处理时间问题时,从网络接口获得的时间,可能是Python的datetime.time类,不等于Pandas的datetime64类,需要用to_datetime()进行格式转换.
5. 优化我的黄金股票自选策略,通过加上更加广义的黄金概念,加上ROE等指标来实验,看看能否更好的优化权重.
6. 如何建立一个py初始化脚本,直接可以在不同的notebook里复用?而不用每次都写额外代码,且不用sys.path.append,直接用import导入.
7. 通过将价格涨跌进行归一化,可以看出他们的 **股价走势** ,但是股价走势曲线相同,不能代表它们的 **相关性** 高. 也就是说,要指数和黄金价格的每一天的涨跌幅 进行对比,来得到相关的结论.
8. 注意Series和DataFrame的关系,取的变量可能是Series,用[]新加一列,对于Series是新加一项而非添加新的一列.
9. Period 和 Datatime 是不同的类型,在用Map进行映射的时候不能混用,必须要让内容和格式 **完全一致** 
10. 在做研究时,想要验证一个结论,必须要考虑到当时的宏观经济背景,不然可能获得一个错误的结论.比如说,以CPI作为通货膨胀的判断标准,可能会受到结构性通胀的影响,正好叠加上中国的牛市或者熊市,因此得到关于股价涨跌的判断实际上可能主要基于市场趋势,而非通胀本身.
11. 在用Series创建Dataframe时,会对数据取并集,如果处理金融数据,遇到不同的交易日,可能存在数据缺失的情况,因此应该先取交集后再形成新的Dataframe.  
12. 再进行金融数据处理的时候,因为基数不同,所以涨幅可能也不一样.比如10->8为-20%,而8->10为25%.应该进行对数化处理,减小极端值影响,且画散点图分析时避免拉伸缩放.
